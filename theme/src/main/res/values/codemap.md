# theme/src/main/res/values/

## Responsibility

Base theme tokens, styles, dimensions, booleans, and Material theme declarations.

## Design Patterns

Central token catalog for Material 2 names, Material 3 color names, state colors, grid size integers, text styles, toolbar style, dialog style, and custom color attributes.

## Data & Control Flow

The base resource table supplies defaults. Qualified folders override selected values for dark mode, API capabilities, and screen size.

## Integration Points

Referenced by `theme` Kotlin extensions, recycler layouts, selection decoration, ui widgets, and consuming apps through theme inheritance.
