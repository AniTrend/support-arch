# analytics/src/main/

## Responsibility

Holds the production Android manifest and Kotlin sources for the analytics module.

## Design Patterns

Minimal Android library source set with a package-only manifest and a Kotlin API contract.

## Data & Control Flow

The manifest contributes no components. Kotlin sources compile into the analytics artifact and expose the contract package.
