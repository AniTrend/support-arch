# ui/src/main/res/values/

## Responsibility

Custom attributes and strings for ui widgets.

## Design Patterns

Styleable definitions for `SupportImageView` and `SupportStateLayout`, plus shared loading text.

## Data & Control Flow

Android generates styleable ids used by custom views to read `aspectRatio` and initial `showState`.

## Integration Points

Referenced from `SupportImageView` and `SupportStateLayout`.
