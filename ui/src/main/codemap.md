# ui/src/main/

## Responsibility

Main source set for UI Kotlin components, custom attributes, strings, and state layout XML.

## Design Patterns

Screen scaffolding module that composes core, recycler, recycler paging legacy, domain, theme, and extension APIs.

## Data & Control Flow

Activities and fragments initialize lifecycle controllers, list fragments wire adapters and presenters, state widgets observe load state flows, and XML resources provide state layout views and custom attributes.

## Integration Points

Depends on extension, core, theme, domain, recycler, recycler-paging-legacy, Material Components, core KTX, SwipeRefreshLayout, and Paging runtime.
